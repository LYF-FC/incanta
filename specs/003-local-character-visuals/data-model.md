# Data model and job transitions

- **VisualIdentity:** conversation UUID, revision positive integer, private reference/workflow identifiers, optional LoRA identifier, approved_portrait_asset nullable; paths remain behind configured local roots. Settings/context revision changes invalidate pending publication.
- **RenderJob:** UUID, unique `(conversation_id, request_id)`, kind `portrait|manual|automatic`, settings/context/identity revisions, originating turn nullable, owned renderer prompt ID nullable, state `queued|submitting|running|cancel_requested|succeeded|failed|cancelled|uncertain`, created/updated UTC timestamps and bounded public error code. Prompt scene description `1–2000 characters`; seeds/settings stored locally.
- **Asset:** UUID, owning conversation/job, media type `image/png|image/jpeg|image/webp`, byte count `1–20971520`, checksum, configured-root relative file key; dimensions `1–8192 pixels per axis`. Validate actual decode/type, traversal and symlinks before serving; extensions alone are insufficient. Approved assets require an explicit owner action.
- **ScenePolicy:** conversation, enabled default false, cooldown_seconds `60–3600`, default 300, last automatic enqueue time, latest pending proposal; one automatic job per conversation. Limits: five pending manual requests globally, total pending jobs ten, one running render.
- **ResourceLease:** process operational state with holder/type and current job; persist job ownership, not a stale live lock. On restart reconcile active work before issuing a new heavy lease.

Transitions: queued → submitting → running → succeeded/failed; queued → cancelled; running → cancel_requested → cancelled or discard completed result. Submit ambiguity → uncertain; only reconciliation/explicit owner resolution leaves uncertain. Lost connection is not automatically failed/cancelled. On revision change, suppress/cancel stale work; obsolete output must not become current. Save artifact atomically before successful asset/job DB commit; clean unreferenced partial output only within owned temporary paths.
