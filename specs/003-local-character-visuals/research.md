# Research and decisions

**Date:** 2026-11-17. Primary-source review and research-agent findings; no installation or render performed.

- **Decision:** use ComfyUI's prompt/history/view contract behind an adapter and owned durable jobs. **Rationale:** separates local UI from renderer availability. **Alternative:** browser button automation cannot provide durable application ownership. [Official routes](https://github.com/Comfy-Org/docs/blob/main/development/comfyui-server/comms_routes.mdx).
- **Decision:** capability-test targeted cancellation; never global interruption of unrelated jobs. Current upstream has targeted jobs/interrupt behavior, but an older local installation may differ. **Alternative:** assume `/interrupt` is safely targeted on every version—rejected. Pin exact tested server revision during setup. [Server implementation](https://github.com/Comfy-Org/ComfyUI/blob/master/server.py).
- **Decision:** integrate Photoshoot's exported API prompt with hidden builder state, not raw canvas JSON. **Rationale:** state lives in node.properties and the graphToPrompt hook resolves hidden inputs. **Alternative:** assume node panels/series queue run headlessly—rejected. Pin Photoshoot revision and validate headless output. [Internals](https://github.com/ralksta/ComfyUI-Photoshoot/blob/main/docs/internals.md), [serialization hook](https://github.com/ralksta/ComfyUI-Photoshoot/blob/main/js/shared.mjs).
- **Decision:** preserve existing LoRA as an optional evaluated asset; no guaranteed identity from text prompts. **Rationale:** Photoshoot mostly emits text; diffusion model/checkpoint/identity adapter determine face consistency. **Alternative:** promise its example model fits M2 or reproduces references—unsupported. [Quickstart](https://github.com/ralksta/ComfyUI-Photoshoot/blob/main/docs/quickstart.md).
- **Decision:** serialize model residency and measure unload/handoff. **Rationale:** M2/16 GB shared memory and owner accepts slow scenes. **Alternative:** load LLM/diffusion together without measurement—rejected. ComfyUI `/free` exists but does not prove hardware memory release. Model selection is a gated compatibility experiment, with no download until explicitly chosen.

Architecture decisions are resolved. Exact model/workflow/server checksums and face quality are outputs of the explicit asset/setup evaluation tasks, not unanswered product questions or claimed compatibility.
