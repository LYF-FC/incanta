# Security and privacy

This private repository contains an experimental local application, not a hardened service. Use synthetic data and local-only access.

Do not include private memories, conversations, personality definitions or secrets in commits, pull requests, issues, screenshots or logs. Models and ComfyUI media also stay outside Git. A private repository is not a secrets vault.

Report security concerns directly to the repository owner through an established private channel. Do not post credentials or private data in an issue.

If a credential is accidentally committed, revoke or rotate it first, stop pushing affected history, and coordinate a history cleanup with the owner. Removing a file or adding an ignore rule does not remove it from past commits.

The repository checker detects selected patterns only. Review content manually; do not treat a passing check as proof that all sensitive information was removed.
